# Self-Improving AI: Discord Paste

> **TL;DR:** The [self-improving AI reading list](../guides/self-improving-ai/reading-list.md) formatted to paste into Discord.
> **Updated:** October 2026  ·  About 2,400 characters.

## How to use it

- Copy everything inside the code block below and paste it into Discord.
- It fits in **one message with Nitro** (4,000-character limit). Without Nitro (2,000 characters), post it as two messages, splitting at the `## 🏋️` header.
- The `<>` around each link stops Discord from generating a preview card for every link.
